它常驻菜单栏。复制视频链接，打开面板（会自动填入），选择画质，即可下载到本地。内置 yt-dlp + ffmpeg，自动处理国内/国外站点的网络分流。

- 🪶 **轻巧**：原生 Swift + SwiftUI，无第三方依赖
- 🔗 **常见视频网站**：内置下载引擎；个别站点走专用解析。视频号能识别，但不支持下载
- 🌐 **智能分流**：国内站强制直连，国外站自动探测本地 Clash 代理端口
- 🍪 **登录态**：需要登录才能稳定下载的站点，自动读取本机 Chrome Cookie
- 📋 **剪贴板自动收集**：常驻监听剪贴板——浏览器里每复制一条链接就自动加入下载列表（面板内可关闭）；也可从文本里整段复制多条，自动去重
- 📚 **批量队列下载**：多条链接排队依次下载，进度显示「第 n/N 个」；单个失败不中断队列，全程只在结束时通知一次
- 📊 **进度与通知**：实时进度条，完成后系统通知，点击打开保存目录
- 🔍 **检查更新**：一键查询 GitHub Releases；有新版可在面板里直接安装并重启，也可打开网页下载

> 📦 **直接下载**：前往 [Releases](https://github.com/aright8-sys/VideoGrab/releases/latest) 下载打包好的 `VideoGrab.zip`，或按下方说明自行构建。

### v2.2 — Vimeo 下载与稳定性加固

- 🎬 **新增 Vimeo 下载**：普通下载路已被挡住，改为用本机 Chrome 过验证、再把分片拼成文件（需要装着 Google Chrome）。

- 🔄 **ffmpeg 跟随 App 更新**：用户目录里的 ffmpeg 加了版本指纹，升级 App 后自动换新，不再永远停在首装版本；yt-dlp 依旧走「更新内核」自我升级、绝不被覆盖。
- 🧵 **修复两处小概率状态错乱**：通知跳转目录加锁防并发读写；取消下载后旧任务的迟到回调一律作废——手快立刻开新下载，进度和结果也不会互相污染。

- ✅ **新增自动化测试**：13 条测试钉住各站点解析逻辑（域名匹配 / 链接剪裁 / 进度解析 / 新片场画质选择 / 微信短链 / Pinterest→Vimeo 判定 / Vimeo 清单解析），改完代码跑一次 `swift test` 即知有没有改坏。

## 工作原理

### 网络分流

不同站点对代理的需求相反，App 会按目标域名自动选择：

| 类型 | 走法 |
| --- | --- |
| 国内站 | 直连 |
| 需登录的站 | 自动读取 Chrome Cookie |
| 国外站 | 走本地 Clash 代理（7897/7890 等） |
| Vimeo | 本机 Chrome 解析（yt-dlp 提取器已坏） |
| 视频号 | 识别标题，不提供下载 |

App 启动时会清理继承来的 `*_proxy` 环境变量，避免 GUI 与终端行为不一致。

### 下载内核

首次构建时 `build-app.sh` 会下载 yt-dlp 和 ffmpeg 到 `Resources/bin/`，打包进 `.app`。
首次运行时复制到 `~/Library/Application Support/VideoGrab/bin/`（可写、可自更新）。

### 「更新内核」是什么？

面板底部的「更新内核」指的就是升级下载引擎 **yt-dlp**。VideoGrab 本身只是图形外壳，真正解析网页、抓取视频流、合并音视频的工作全部交给内置的 yt-dlp（配合 ffmpeg）完成，所以它被称为「下载内核」。

各视频网站经常改版或调整反爬策略，旧版 yt-dlp 可能因此下载失败。**当某个链接突然下不动时，先点一次「更新内核」**：

- 执行 `yt-dlp -U`，从 GitHub 拉取并自我升级到最新版；
- GitHub 属国外站点，会自动走探测到的本地代理（无代理则直连）；
- 升级的是 App Support 目录里那份可写副本，**无需重装 App**；
- 完成后底部会显示新的版本号。

### 「检查更新」是什么？

面板右下角的「检查更新」用于升级 VideoGrab 本体。它向 GitHub Releases 查询最新版本号，与本机版本做比较：

- **有新版本**：面板里弹出横幅。若 Release 提供了 `VideoGrab.zip` 和 sha256，可点「立即更新」：下载后校验哈希与 Bundle，再替换并自动重启；也可点「网页下载」打开 Release 页。
- **已是最新**：短暂提示当前版本号；
- 查询走 GitHub API（国外站点，自动走本地代理或直连）；匿名 API 限额每小时 60 次，手动点击完全够用。
- 自动更新只接受本仓库、带具体 tag 的 GitHub 资产地址，并用 GitHub 提供的 digest 做 SHA-256 校验。无开发者证书，因此校验通过后才会清除隔离属性并做 ad-hoc 签名，以便新实例能被拉起。


## 构建与运行

需要 macOS 14+ 和 Swift 工具链（Xcode 或 Command Line Tools 即可，无需打开 Xcode）。

```bash
./build-app.sh            # 编译并打包成 VideoGrab.app
open VideoGrab.app        # 运行
cp -r VideoGrab.app /Applications/   # 安装（可选）
```

开发调试：

```bash
swift build               # 仅编译
swift test                # 跑解析器测试
```

## 使用

1. 启动后点击菜单栏的 ⬇️ 图标。
2. 复制视频链接——一条或多条都行，也可以在文本文档里整段复制。链接会被自动收集进面板列表，无需手动粘贴。
3. 选择画质，点击「开始下载」。多条链接时按钮会显示数量并排队依次下载，结束时只通知一次。
4. **需要登录的内容**：若弹出「Chrome Safe Storage」钥匙串窗口，点「始终允许」+ 输入开机密码（只需一次）；请先在 Chrome 里登录对应网站。
5. **YouTube 等国外站**：需先启动本地 Clash 等代理。
6. **Vimeo**：需要本机装着 Google Chrome。
7. **微信视频号**：暂不支持下载。
8. **检查更新**：点面板右下角的「检查更新」查询新版本；有新版可一键安装。剪贴板自动收集可在链接列表工具条里关闭。
